

## Tri-Fold Brochure: Causeio

Standard tri-fold = 6 panels (front side has 3, back side has 3). The fold order matters because of how it opens.

```text
BACK SIDE (printed first when folded):
┌─────────────┬─────────────┬─────────────┐
│  Panel 6    │  Panel 1    │  Panel 2    │
│  Back       │  Inside Flap│  Front Cover│
│  Cover      │  (folds in) │             │
└─────────────┴─────────────┴─────────────┘

INSIDE (revealed when fully opened):
┌─────────────┬─────────────┬─────────────┐
│  Panel 3    │  Panel 4    │  Panel 5    │
│  Inside Left│ Inside Mid  │ Inside Right│
└─────────────┴─────────────┴─────────────┘
```

## Design Notes
- **Palette:** brand green `#57cc99` (primary), deep teal `#1f5f7e` (panel headers/accents), warm cream `#FCF6F5` (background), charcoal `#1a1a1a` (body text). Rose/amber/sky used only as small category accents on panels 3/4/5 to mirror the landing page.
- **Type:** Bold geometric sans for headlines (e.g., Poppins or Inter Bold), humanist sans for body (Inter or Source Sans).
- **Imagery:** Real volunteer/community photography on cover; flat illustrated icons inside (consistent with the landing page tile style — no clip art).
- **Print specs:** 8.5" × 11" landscape, tri-fold (letter fold), 0.375" bleed, 0.25" safe margin from each fold. Right-fold flap (Panel 1) sized 1/16" narrower than the others so it tucks cleanly.
