What You Should See:

  • Text saying "Causeio Support" and "How Can I Help You Today?"

Troubleshooting:

  • Widget doesn't appear: Check browser console for errors
  • Widget appears but doesn't work: Verify chatbot is active in database
  • No AI responses: Check OPENAI_API_KEY is set in Supabase
  • CORS errors: Verify files are in the public widget-hosting bucket
